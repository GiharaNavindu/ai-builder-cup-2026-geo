**Climate Copilot** is an autonomous disaster resilience and critical infrastructure protection platform designed for extreme monsoon flash-flood events. 

Built for the **AI Builder Cup 2026** under the theme **Sustainability & Social Impact**, it grounds generative multimodal AI reasoning into deterministic Earth Observation radar telemetry and BigQuery spatial joins to eliminate hallucinations and trigger automated emergency dispatches.

---

## The Problem & Innovation

- **Monsoon Cloud Penetration**: Optical satellites (Sentinel-2, Landsat) fail completely under dense monsoon rain clouds. Climate Copilot uses **Sentinel-1 Synthetic Aperture Radar (SAR)** that penetrates clouds day and night to map water surfaces with zero latency.
- **Zero-Hallucination Grounding**: Rather than letting an LLM guess coordinates or damage estimates, a deterministic Google Earth Engine and BigQuery GIS pipeline extracts millimeter-accurate water masks and spatial joins (`ST_Intersects`), forcing **Gemini 2.5** to cite verified physical metrics in every advisory.
- **Case Study Ground Truth**: Evaluated against the real **May–June 2024 Kelani River Basin / Kaduwela–Biyagama flash floods**, preventing isolation of Biyagama Divisional Hospital and electrical failure at the Biyagama 132kV Grid Substation.

```
[ Split-Screen Command Center UI (React + Leaflet) ]
 ├── Left Canvas (Kavindu): Leaflet Map + GEE SAR Tile Layer + Before/After Opacity Slider + OSM Markers
 └── Right Panel (Gihara): Telemetry Cards + ADK Mitigation Playbook + Live Pub/Sub SSE Event Terminal
                               │
                               ▼ (HTTPS on Cloud Run — Port 8080)
[ FastAPI + Google ADK Multi-Agent Orchestrator (Gihara) ]
 ├── Stage 1: Geospatial Telemetry Engine (Kavindu)
 │    ├── Google Earth Engine API → Sentinel-1 SAR Flood Mask + CHIRPS Rain + WorldPop
 │    └── BigQuery GIS → ST_Intersects(Flood_Polygon, OSM_Roads / Hospitals / Substations)
 │
 ├── Stage 2: Vertex AI Multi-Agent Pipeline
 │    ├── Agent 1 (Kavindu): Multimodal SAR & Vulnerability Analyst (Gemini 2.5 Flash/Pro)
 │    └── Agent 2 (Gihara): Infrastructure Cascade & Dispatch Coordinator (Google ADK)
 │
 └── Stage 3: Event Dispatcher (Gihara)
      └── Cloud Pub/Sub Topics (`infra-grid-substation-alerts`, `infra-logistics-corridor-reroute`)
```

## Shared Data Contracts

1. **Contract 1: Geospatial Telemetry ([telemetry_payload.json](file:///e:/Github/ai-builder-cup-2026-geo/backend/cache/kelani_golden.json))**:
   - Produced by Kavindu's Geospatial Engine and consumed by Gihara's ADK orchestrator.
   - Strictly enforced via Pydantic model `TelemetryPayload` in [backend/ai/schemas.py](file:///e:/Github/ai-builder-cup-2026-geo/backend/ai/schemas.py).
2. **Contract 2: Mitigation Playbook ([kelani_playbook_golden.json](file:///e:/Github/ai-builder-cup-2026-geo/backend/cache/kelani_playbook_golden.json))**:
   - Generated by Gemini 2.5 multimodal analysis with mandatory metric citations.
   - Strictly enforced via Pydantic model `PlaybookResponse`.

## Quick Start (Backend Engine)

```powershell
# 1. Clone repository & setup virtual environment
git clone https://github.com/GiharaNavindu/ai-builder-cup-2026-geo.git
cd ai-builder-cup-2026-geo
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. (Optional) Authenticate with your Google Earth Engine project
earthengine authenticate
earthengine set_project <YOUR-GEE-PROJECT-ID>

# 3. Run the end-to-end verification test suite
python backend/test_pipeline.py
```

For comprehensive technical details on the satellite radar algorithms and GIS models, see the [Backend Documentation](file:///e:/Github/ai-builder-cup-2026-geo/backend/README.md).
